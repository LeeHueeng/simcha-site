# simcha-site

심플차계부(com.hueeng.car) 공개 문서 사이트 — GitHub Pages.

- `/` 지원·문의
- `/privacy` 개인정보처리방침
- `/terms` 이용약관
- `/account-delete` 계정 삭제 안내 (Google Play 데이터 보안 양식 "계정 삭제 요청 URL")

앱 내 링크는 `https://car.hueeng.com/{privacy,terms}` 를 가리키므로, Cloudflare DNS 에서 `car` CNAME 을 `leehueeng.github.io` 로 바꾸고 이 저장소 Settings › Pages 에 커스텀 도메인을 설정하면 기존 링크도 살아난다.
